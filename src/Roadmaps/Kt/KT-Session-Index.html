🧠 Mental Model (keep this in mind the whole time)

One sentence to remember
An LLM is a smart brain that can only talk. A tool gives it hands to fetch real data or take an action. An agent is the rulebook that tells the brain which hands to use and when. MCP is the universal plug that lets any brain use any set of hands — safely and in a standard way.

📖 Glossary (quick reference)

LLM (Large Language Model)
An AI trained to understand and generate text (e.g., GPT, Claude). It has no live data on its own.
Agent
An LLM plus instructions and tools, so it can decide actions and call tools to complete a task.
Tool
A single action the AI can call — usually a function that hits one API/endpoint and returns data.
MCP (Model Context Protocol)
An open standard for connecting AI apps to tools and data — "USB-C for AI."
MCP Host
The AI application the user talks to (ChatGPT, Claude Desktop, our GenAI platform).
MCP Client
The connector inside the host that speaks the MCP protocol to a server.
MCP Server
The program that exposes tools/data over MCP (our SXe MCP server is one).
Tool Call
The moment the LLM decides to run a tool and the server executes it.
SXe / ERP
Infor Distribution SX.e — the ERP whose APIs our tools call.
IBC Context
The "screen context" (company, product, vendor, PO the user is viewing) passed to the agent.
Orchestrator
The layer that routes a user question to the right agent.
Token
A chunk of text the LLM processes; more tokens = more cost and slower responses.

❓ FAQ

Does MCP replace our ERP screens?

No. It gives a conversational way to get answers and take actions by calling the same APIs the screens use. The UI stays.

Is it secure? Can it change data?

Yes to both, carefully. Reads are safe; writes (like PO acknowledgment) go through a confirmation gate and reuse the ERP's own validations. Auth and company context are enforced, never hardcoded.

Is this the same as Amazon's "Ask Rufus"?

Conceptually yes — Rufus answers by calling APIs behind the scenes instead of making you navigate screens. Our agents do the same for the ERP.

Do we have to expose a database directly?

No. We expose existing ERP endpoints as tools. Database-as-MCP and external servers (Jira, etc.) are other valid patterns covered in Session 2.

What's a "tool" vs an "agent"?

A tool is one action (hands). An agent is the instructions deciding which tools to use and when (the brain's rulebook).
